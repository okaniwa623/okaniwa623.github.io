プライバシーポリシー

gas-mcp（以下「本ツール」）における Google ユーザーデータの取り扱いについて。

最終更新: 2026年9月8日

1. 本ツールの性質

本ツールは、利用者自身の PC 上でのみ動作するローカルプログラムです。 開発者はサーバーやデータベースを一切運営しておらず、 利用者の Google アカウントのデータが開発者に送信されることはありません。

2. 取得する情報

本ツールは、利用者が Google アカウントで承認した範囲において、以下の情報にアクセスします。

情報取得の目的
Apps Script プロジェクトのソースコード・ファイル構成 利用者の指示に基づくコードの表示・編集・作成のため
Apps Script プロジェクトのメタデータ（名称、ID、更新日時、所有者） 操作対象のプロジェクトを特定するため
Apps Script のバージョン・デプロイ情報 バージョン管理およびデプロイ操作のため
Apps Script の実行履歴（関数名、実行結果、実行時刻） エラーの調査・デバッグのため
Google ドライブ上のファイル一覧のうち、Apps Script 形式のファイルの名称と ID 操作可能なプロジェクトを一覧表示するため。Apps Script 以外のファイル、およびファイルの内容は取得しません。

本ツールは、利用者の氏名・メールアドレス・連絡先・位置情報・広告識別子等の 個人情報を収集しません。また、アクセス解析やトラッキングも一切行いません。

3. 情報の保存

Google アカウントへのアクセストークンおよびリフレッシュトークンは、 利用者の PC 内の ~/.config/gas-mcp/token.json に、 所有者のみが読み書きできる権限（600）で保存されます。

API から取得したソースコード等のデータは、利用者の指示に応答するあいだ メモリ上で扱われるのみで、本ツールがファイルとして永続化することはありません。

4. 情報の共有

本ツールは、取得した情報を第三者に販売・提供・開示しません。 情報の送信先は、以下の 2 つに限られます。

  1. Google の API サーバー — 利用者の指示を実行するために必要な通信。
  2. 利用者自身が接続した AI アシスタント（MCP クライアント） — 本ツールは MCP サーバーとして動作するため、利用者が「このスクリプトを読んで」等と 指示した場合、その応答としてソースコード等が接続先の AI アシスタントに渡されます。 これは本ツールの機能そのものであり、利用者の明示的な指示によってのみ発生します。 渡された先でのデータの取り扱いは、当該 AI アシスタントの提供者のプライバシーポリシーに従います。

上記以外の外部への送信は行いません。

5. 情報の保護

  • Google API との通信はすべて HTTPS で暗号化されます。
  • 認証情報は利用者の PC 内にのみ保存され、所有者以外は読み取れない権限を設定します。
  • 認証には OAuth 2.0 を用い、本ツールが Google アカウントのパスワードを取得することはありません。

6. アクセス権の取り消しとデータの削除

利用者はいつでも、以下の操作によりアクセスを完全に遮断できます。

  1. Google アカウントの 「サードパーティ製アプリとの連携」 から本ツールを選び、アクセス権を削除する。
  2. PC 上の ~/.config/gas-mcp/ ディレクトリを削除する。

これにより保存されていたトークンは失効・消去され、本ツールは以後 利用者のいかなるデータにもアクセスできなくなります。

7. Google API サービスのユーザーデータに関するポリシーへの準拠

本ツールによる Google API から受け取った情報の使用および他者への移転は、 Google API サービスのユーザーデータに関するポリシー （限定的使用に関する要件を含む）に準拠します。

8. 本ポリシーの変更

本ポリシーを変更する場合は、このページを更新し、最終更新日を改めます。
