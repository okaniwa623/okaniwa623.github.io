gas-mcp

Google Apps Script のプロジェクトを、AI アシスタント（MCP クライアント）から 直接読み書き・デプロイするための個人用ツールです。

できること

利用者の PC 上で動作し、Google の Apps Script API と Drive API を通じて、 利用者自身が所有する Apps Script プロジェクトを操作します。

  • Apps Script プロジェクトの一覧表示と検索
  • スクリプトのソースコードの読み取り
  • ソースコードの編集・ファイルの追加と削除
  • バージョンの作成とデプロイ（ウェブアプリ等の更新）
  • 実行履歴の確認（エラー調査のため）

動作のしくみ

本ツールは 利用者の PC 上でのみ動作するローカルプログラムです。 開発者が運営するサーバーは存在せず、利用者のデータが開発者に届くことはありません。 

利用者の PC
  ├─ AI アシスタント（MCP クライアント）
  └─ gas-mcp  ──────▶  Google API（Apps Script / Drive）

Google アカウントの認証情報（アクセストークン）は、 利用者の PC 内（~/.config/gas-mcp/）にのみ保存されます。

利用するデータと権限

本ツールは、以下の Google API スコープへのアクセスを求めます。 それぞれの用途は下表のとおりで、これ以外の目的には使用しません。

スコープ用途
script.projectsスクリプトのソースコードの読み取りと書き込み
script.deploymentsバージョンの作成とデプロイ
script.processes実行履歴の取得（エラー調査）
script.metrics実行回数などのメトリクス取得
drive.metadata.readonlyApps Script プロジェクトの一覧取得（ファイル名と ID のみ。ファイルの中身は読みません）

データの取り扱いの詳細はプライバシーポリシーをご確認ください。

ソースコード

本ツールは個人利用を目的として開発されたものです。実装は 開発者の GitHub アカウントで管理しています。

利用をやめるとき

Google アカウントの 「サードパーティ製アプリとの連携」 から本ツールのアクセス権を削除すると、以後一切のアクセスができなくなります。 あわせて PC 上の ~/.config/gas-mcp/ を削除してください。
