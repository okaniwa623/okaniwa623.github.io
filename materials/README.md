# 資料置き場

クライアントや関係者から受け取った資料・画像の原本を置く。

**このリポジトリは公開なので、原本は git に入れない（手元のマシンにだけ置く）。** 追跡するのはこの README と `inbox/.gitkeep` だけ。

## 使い方

- **ユーザー:** 受け取ったファイルを `inbox/` に置くだけ。名前・形式はそのままでよい。
- **Claude:** `inbox/` にファイルがあれば中身を確かめ、サブフォルダを作る・名前を変えるなどして整理し、
  下の一覧に1行足す。`inbox/` は空に戻す。サブフォルダの切り方と名前は Claude が決めてよい。
- 原本の中身は書き換えない。縮小・変換したものは使う側（`src/` など）に置く。原本は消さない。
- 名前に日付や版番号を付けない。新しい版が届いたら**同じ名前で上書き**し、古い版は git の履歴で追う。
  いつの版かは下の一覧の「受け取り」に書く。
- `inbox/` の中身は git の対象外（確認前のものを GitHub に上げないため）。整理後のファイルは git で管理する。
